# Getting help

- **Something doesn't work?**
  1. Check *Limitations and notes* in the [README](README.md) and run `probe.bat`. It writes
     `bridge/probe-report.txt` with a pass/fail list.
  2. If that doesn't help, open a [bug report](../../issues/new/choose).
- **Questions, ideas, sharing personas.** Open a discussion in *Discussions*, if enabled, or an issue.
- **Security problems.** See [SECURITY.md](SECURITY.md) and don't post them publicly.

When asking for help, include:
- the game version and DLCs;
- the provider and model you use;
- the relevant lines from the bridge window.

**Remove your API key from anything you paste.**
